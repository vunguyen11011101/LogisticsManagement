# Logistics Management (Odoo Module)

## Description
Module quản lý vận chuyển được phát triển trên Odoo (OpenERP)

## Features
- Quản lý khách hàng
- Quản lý đơn hàng
- Quản lý kiện hàng
- Quản lý đối tác giao hàng

## Tech Stack
- Python (Odoo Framework)
- PostgreSQL

## My Role
- Thiết kế database (models)
- Xây dựng logic xử lý đơn hàng
- Tạo giao diện (XML views)

## How to run
1. Cài Odoo
2. Copy module vào thư mục addons
3. Activate module trong Odoo
